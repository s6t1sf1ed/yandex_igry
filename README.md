# Верити: Бэкрумс

Рабочий прототип браузерного лиминального хоррора для Яндекс Игр. Первый уровень проходит в Закулисье и состоит из зон «Жёлтые комнаты» и «Водопровод мечты». Название игры пока временное.

## Стек

- TypeScript 7
- Vite 8
- Babylon.js 9
- WebGL, без сервера и без внешних API во время игры
- отдельный `PlatformBridge` для будущей интеграции SDK Яндекс Игр

Такой стек даёт прямой контроль над весом сборки, временем загрузки, мобильным управлением и событиями SDK. Unity WebGL для первого релиза не используется из-за более тяжёлой сборки и запуска в браузере.

## Что уже есть

- минимальная 3D-сцена от первого лица;
- лабиринт с коллизиями;
- взаимодействие клавишей `E`, записка, ключ и запертый выход;
- универсальный реестр интерактивных объектов и HUD-инвентарь сюжетных предметов;
- переход между «Жёлтыми комнатами» и «Водопроводом мечты» с отдельной атмосферой и контрольной точкой;
- главное меню с продолжением, отображением сохранённой зоны и выбором уже открытых уровней;
- короткие переходные заставки для служебной двери, шахтного подъёмника, портала и финального лифта;
- три сохраняемых вентиля, циклические паровые препятствия и аварийный выход;
- Верити с состояниями сна, патруля, обнаружения, погони и поиска;
- поиск пути по карте, зрение с учётом стен и реакция на шум игрока;
- экран поражения и повтор с сохранением собранных предметов в текущей сессии;
- постоянное локальное сохранение ключа, записок и прохождения с миграцией старого формата;
- журнал найденных записок, открываемый клавишей `J`;
- процедурные звуки шагов, обнаружения, предметов и окружения без внешних аудиофайлов;
- кнопка полного отключения звука;
- фонарь с расходуемым и сохраняемым зарядом, переключением по `F` и запасной батареей;
- два укрытия, в которых Верити не видит, не слышит и не может схватить игрока;
- процедурные воксельные текстуры стен, пола, потолка и шкафчиков;
- мобильное управление: виртуальный стик, свайп обзора и отдельные кнопки действия, фонаря и журнала;
- автоматический запрос полноэкранного режима на сенсорных устройствах;
- пауза при потере pointer lock;
- платформенный адаптер, который позже будет переключён с `localStorage` на облако Яндекс Игр.
- четыре игровые главы: Бэкрумс, Кубические шахты, Лаборатория наблюдения и трёхфазная битва в Камере подавления.

## Запуск

```powershell
npm install
npm run dev
```

Проверка production-сборки:

```powershell
npm run build
npm run preview
npm run test:menu
```

Для локальной проверки мобильной раскладки на desktop можно открыть сборку с параметром `?touch=1`. Параметр `&autostart=1` автоматически запускает сцену и предназначен только для smoke-тестов.
